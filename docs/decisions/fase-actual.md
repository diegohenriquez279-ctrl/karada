## Qué es este archivo

Este archivo es un **puntero**, no una copia. Contiene solo la referencia a la fase vigente. Las decisiones viven en el archivo `fase-N.md` correspondiente y nunca se duplican aquí.

Cuando se cierre una fase y comience la siguiente, se edita únicamente la línea de referencia de arriba. El archivo `fase-N.md` de la fase cerrada queda intacto como documentación histórica.
